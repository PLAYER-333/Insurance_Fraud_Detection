# Confusion Metrics
A confusion matrix is a summary table used to evaluate the performance of a classification model by comparing its predicted labels against the actual ground-truth values.


# Corealtion Heatmap
A 2D colored grid that displays the statistical relationship (correlation coefficients) between multiple variables in a dataset.

# Feature Importance
Feature importance is a technique that assigns a score to each input variable in a dataset based on how much it helps a machine learning model make predictions.

# Accuracy
Accuracy: The fraction of total predictions your model got right out of all predictions made.

# Precision 
Out of all the positive classes the model predicted, how many were actually positive? (Focuses on minimizing false positives).

# Recall (Sensitivity)
Out of all the actual positive cases in the data, how many did the model find? (Focuses on minimizing false negatives).

# F1 Score 
The harmonic mean (balanced average) of precision and recall.

# ROC Curve & AUC 
The ROC (Receiver Operating Characteristic) curve plots the True Positive Rate against the False Positive Rate at different classification thresholds. The AUC (Area Under the Curve) measures the total area beneath that curve. An AUC of 1.0 means a perfect model, while 0.5 means random guessing.
